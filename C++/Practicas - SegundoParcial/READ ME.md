# Prácticas de Programación Orientada a Objetos

Cinco ejercicios para practicar los siguientes conceptos:

1. **Herencia:** clase `Vehiculo` con dos clases derivadas, `Auto` y `Motocicleta`, con atributos propios y el método `mostrarInfo()` sobrescrito.
2. **Polimorfismo:** colección de autos y motocicletas tratados como vehículos, donde cada uno muestra su información específica.
3. **Sobrecarga de operadores:** clase `Fraccion` con los operadores `+` para sumar y `==` para comparar equivalencias.
4. **Sobrecarga de métodos:** clase `Calculadora` con versiones de `sumar()` para dos enteros, tres enteros y dos decimales.
5. **Iteradores:** recorrido de una colección de vehículos mediante un iterador para imprimir su información.

## Objetivo

Aplicar herencia, polimorfismo, sobrecarga e iteradores en ejercicios sencillos.
